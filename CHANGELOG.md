# Changelog

## [0.1.0] - 2026-03-08

### Added
- `hyprflow save [name]` — save current Hyprland session
- `hyprflow restore [name]` — restore saved session with window positioning
- `hyprflow list` — list saved sessions
- `hyprflow delete <name>` — delete a saved session
- `hyprflow config` — show current configuration
- Kitty terminal: restore CWD + hint of last command
- Configurable ignore list for transient windows
- TOML configuration at `~/.config/hyprflow/config.toml`
- `--dry-run` flag for restore preview
- `--verbose` flag for detailed output
- AUR PKGBUILD for Arch Linux
